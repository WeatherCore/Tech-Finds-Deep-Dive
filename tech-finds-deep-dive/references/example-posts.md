## 示例 1:开源分享 × 技术博主(模板 5)

### 背景(步骤 2-5 产出)

- 项目:虚构 Python 框架 MiniRAG —— 轻量 RAG 全流程封装(文档切分→向量化→检索→生成)
- 技术栈:FastAPI + LangGraph 状态机,不用 ORM 直接写 SQLite,启动约 200ms,内置 12 套 prompt 模板
- 卖点清单节选:
  - 差异化卖点:链路可单步调试 / 启动约 200ms / 单文件 SQLite 零外部依赖 / 文档每条配置附可复制示例 / 插件式数据源 / 不用 ORM 的设计取舍
  - 画像:大三学生课设(从 2 周缩到 1 天跑通)/ 转码人做企业知识库(调试不用瞎猜哪层挂)/ 技术博主找对比基准线(文档全、结构清)
  - 竞品:vs LangChain 官方实现(文档散、概念多)、vs LlamaIndex(强绑抽象层、难魔改),均说清 trade-off
  - 反直觉卖点:核心不是检索而是 prompt 模板管理——调 prompt 比换检索策略收益更大
- 人设:技术博主(自动匹配:框架/库/开源项目 → 技术博主)
- 模板:模板 5 开源分享

### 最终文案

**主推标题**:开源分享:三周实测轻量 RAG 框架,MiniRAG 是少数能把链路单步拆开看的

**备选标题**:
1. 实测 3 个轻量 RAG 框架,这个 200ms 启动的冷门项目被低估了
2. 不吹不黑:MiniRAG 源码精读,核心居然不是检索

**正文**:

这几个月我把 GitHub 上 star 靠前的轻量 RAG 框架基本都跑了一遍,今天先聊一个比较冷门但很能打的:MiniRAG。

先给结论:它是我目前跑过的里面,少数几个调试时能把链路"单步拆开"看的。作者用了 LangGraph 状态机,从文档进来到答案出去,每一步状态都能打出来,排查问题不用再瞎猜是哪一层挂的。单凭这一点,就值一颗 star。

三个实测数据:
- 从装依赖到跑通第一个问答,我计时 4 分 20 秒,同类框架基本 10 分钟起
- 启动约 200ms,原因是作者没引 ORM,直接写的 SQLite,后面聊这个取舍
- 默认配置下 3 万条文档建索引,检索响应稳定在百毫秒级

看到源码才发现重点:这个项目的重心其实不是检索,是 prompt 模板管理,内置 12 套分场景预设。调 prompt 对回答质量的影响经常比换检索策略大,作者显然是摸到门路了。

对比一下(只讲真实差异):LangChain 官方实现文档散、概念多,新手容易绕晕,MiniRAG 的文档每条配置都带能直接复制的示例;LlamaIndex 强绑自己的抽象层,想魔改某一层比较别扭,MiniRAG 每层都能直接改。

短板也说清楚:社区小、issue 响应看运气,插件生态刚起步。团队长期维护我更建议官方那套稳的;个人项目、课设、demo,MiniRAG 更省心。

项目地址放评论区置顶,下期拆它的状态机实现。

## 示例 2:学生党必备 × 学生党(模板 7)

### 背景(步骤 2-5 产出)

- 项目:虚构开源 CLI 工具 Note2Card —— 把 Markdown 笔记按标题层级自动拆成"问题式"复习卡片,导出 Anki apkg
- 技术栈:单文件 Python(约 300 行),本地离线运行,支持数学公式
- 卖点清单节选:
  - 差异化卖点:本地离线、笔记不出本机 / 标题层级自动拆卡免手动录入 / 问题式提问而非摘抄式 / 一键导出 Anki apkg / 300 行注释清晰适合读源码 / 公式卡不乱码
  - 画像:大三期末周复习(手抄卡片 3 小时→1 分钟)/ 考研党整理错题 / 大一新生不知道从哪复习起
  - 竞品:vs Anki 手动制卡(费时)、vs 在线背题 App(要钱、笔记上传云端),均说清 trade-off
  - 反直觉卖点:不接 AI 出题,只做规则拆解+提问模板——不会编造题目,复习心里有数
- 人设:学生党(自动匹配:学生项目/教学类 → 学生党)
- 模板:模板 7 学生党必备

### 最终文案

**主推标题**:学生党必备:期末周笔记一键变卡片,这个开源小工具帮大忙

**备选标题**:
1. 家人们谁懂啊!期末复习我用一个 300 行的小工具省了 3 小时
2. 秋招简历没东西写?这个能读懂源码的小工具很适合练手

**正文**:

家人们谁懂啊!期末周前一周我才发现笔记记了三万字,背是背不完了,翻都翻不完。

然后我挖到了 Note2Card 这个开源小工具,真的是课设救星。它把 Markdown 笔记按标题层级自动拆成一条一条的问题卡片,不是那种"摘抄一遍"的假复习,是把你记的每个知识点转成"这章会考什么"的提问形式,还能一键导出 Anki 的 apkg 文件,手机上通勤刷题直接续上。

亲测用了三天,说下真实感受:
- 三万字的笔记,转卡加导出大概一分钟,之前我手抄卡片一张要两分钟
- 数学公式支持得好,离散数学的公式卡没有乱码
- 关键是本地跑,笔记不出自己电脑,不用把笔记传到别的云端

让我特别惊喜的一点:这个工具不乱出题。它只做规则拆解加提问模板,不会像某些 AI 出题那样编造题目,复习起来心里有数。

期末周用得上;而且源码就一个 300 行的 Python 文件,注释写得清楚,计算机专业的兄弟姐妹拿来当练手读源码的项目也很好,亲测能读懂。

开源免费的,链接我放评论区,先码住,期末会谢我。
