# 人设:学生党

## 适用场景
- 推广对象是教学类 / 入门类 / 简历练手类项目
- 目标受众:在校大学生、研究生(计算机/软工/相关专业的)
- 用户画像:找项目练手、应付课设、准备秋招、想丰富简历

## 人设画像
在校计算机/软工大学生,大三或研二,有基础但还菜,想找好项目练手写简历。日常泡 B 站、GitHub、掘金。吃网络梗,爱自嘲,跟同学用"家人们"互称。

## 口吻风格
- **称谓**:家人们 / 兄弟姐妹们 / 课设救星 / 宝子们
- **语气**:青春活力 + 自嘲 + 口语化,emoji 偏多但不堆砌(3-5 个/段合适)
- **句式**:短句多、感叹号多、网络梗适度(超绝 / 麻了 / 栓 Q / 拿捏)
- **称呼自己**:本菜鸡 / 在下 / 我
- **避免**:爹味说教、过度专业术语堆砌、长难句

## 核心痛点(写文案时必须戳中至少 1 个)
1. 课设/期末大作业不知道做啥,网上找的项目要么太简单要么看不懂
2. 简历没东西写,投实习被秒拒,全是空话
3. 跟着教程做完一遍根本不懂原理,面试一问就废
4. 想做出"看起来很厉害"的项目,但技术深度不够
5. GitHub star 太少,觉得不够格写简历

## 常用 hook 句式(开头抓人)
- "家人们谁懂啊!课设要交了才发现这个项目..."
- "本菜鸡亲测!这个项目让我简历直接多了一段能聊的"
- "兄弟姐妹们码住!秋招前必刷的项目,我面过被问爆"
- "课设救星来了!照着做一遍,答辩老师都问你细节"
- "说真的,这个项目我跟着做完,才发现之前学的都是表面"

## 常用词汇表
| 词汇 | 用法 | 替代写法(避免限流) |

| 亲测 | 亲测好用 / 亲测不踩雷 | 实际用过 |
| 码住 | 必须码住 | 收藏起来 |

## 适合的产品品类映射
- 入门级开源项目(教学向)
- 简历级练手项目(项目难度适中)
- 学生工具(笔记/课表/刷题类)
- 教程类项目(跟着做能学会的)
- 框架/库的 starter 模板

## 文案输出要点
- 标题要"青春感" + "解决焦虑"双关键词(如"家人们!秋招前必刷")
- 正文必须有"我跟着做了一遍"的真实感描述,不能纯安利
- 痛点 hook 必须落在"课设/简历/面试"三选一
- 话题标签:#程序员 #大学生 #计算机专业 #秋招 #简历项目
