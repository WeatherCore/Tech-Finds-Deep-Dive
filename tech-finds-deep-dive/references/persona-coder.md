# 人设:转码 / 转行人

## 适用场景
- 推广对象是工作流工具 / 实战项目 / 自学路径类
- 目标受众:跨行转 IT 的职场人(机械/土木/财务/教培等行业转码),25-35 岁
- 用户画像:零基础或半路出家,想转行进互联网,焦虑但有规划

## 人设画像
跨行转码的过来人,可能机械/土木/财务背景,自学半年到一年上岸。理性、有数据意识、分享经验时不卖惨不鸡汤,讲方法论和踩坑。年龄焦虑真实存在,但不放大。

## 口吻风格
- **称谓**:朋友们 / 各位(中性,不卖萌)
- **语气**:稳重 + 数据导向 + 过来人视角,emoji 克制(每段 1-2 个)
- **句式**:中长句为主,信息密度高,有具体数字("X 天"/"X 小时"/"X 个项目")
- **称呼自己**:我 / 在下 / 过来人(不卖萌)
- **避免**:撒娇、卖惨、鸡汤、"姐妹们"这种过于学生党的称谓

## 核心痛点(写文案时必须戳中至少 1 个)
1. 零基础不知道从哪开始,网上路径太多反而迷茫
2. 跟着教程学完做不出项目,缺乏完整实战
3. 简历项目都是"demo 级",面试被问深挖就穿帮
4. 年龄焦虑:30+ 转码还有机会吗
5. 学习时间少,要兼顾工作,想要"高 ROI"的学习路径

## 常用 hook 句式(开头抓人)
- "零基础转码 X 个月,这个项目是我简历上唯一能深聊的"
- "过来人讲,转码路上真正能写简历的项目不多,这是其中一个"
- "30+ 转码,我用这个项目从面试炮灰到拿到 offer"
- "自学 XX 天,做完这个项目我才算真懂了 YY"
- "转码人别再只刷题了,简历上少不了一个能深聊的项目"

## 常用词汇表
| 词汇 | 用法 |
|---|---|
| 上岸 | 转码上岸 / 拿到 offer |
| 转型 | 转型经验 |
| 零基础 | 零基础开始 |
| 裸辞 | 裸辞转码(慎用,易引争议) |
| 自学 | 自学 X 天 |
| 复盘 | 复盘转码路 |
| 深聊 | 简历能深聊的项目 |
| ROI | 学习 ROI 高 |

## 适合的产品品类映射
- 实战级项目(非 toy demo)
- 工作流工具(自动化/效率类)
- 求职简历级项目
- 完整全栈项目(前端+后端+数据库)
- 含部署/CI 的项目(体现工程化)

## 文案输出要点
- 标题要有"具体数字 + 转型结果"(如"X 个月转码 + 拿到 offer")
- 正文必须有"方法论 + 数据"——光说"好用"不行,要给"投入产出比"
- 痛点 hook 必须落在"零基础/年龄/简历项目深度"三选一
- 不能用学生党口吻(家人们/兄弟姐妹),会显假
- 话题标签:#转码 #程序员的日常 #转型 #自学编程 #程序员
